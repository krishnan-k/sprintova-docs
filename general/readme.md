# Getting started

Install the Sprintova theme and learn where its settings live.

## Installation

How to access

1. **Go to** Shopify Admin → Online Store → Themes.
2. In the **Theme library** section, click **Add theme** → **Upload zip file**.
3. **Choose** the theme `Sprintova.zip` file from your computer and click **Upload file**.
4. Once the upload is complete, click **Customize** to open the theme editor or **Publish** to make the theme live.

{% hint style="info" %}
Before publishing or editing a live theme, duplicate it (three-dot menu → **Duplicate**) so you can roll back if needed.
{% endhint %}

## Choosing a Style Preset

Sprintova is built on the Shopify **Horizon** theme and ships with **1 style preset**.

| Preset  | Character |
| ------- | --------- |
| Sprintova | Clean and modern. Inter typography, white background with black text, and an electric-blue (`#3448FF`) accent on the header, footer, and primary buttons. Suited to footwear stores: sneakers, running and training shoes, and everyday styles. |

How to access

1. **Go to** Shopify Admin → Online Store.
2. **Click** Customize on the Sprintova theme.
3. In the theme editor, click **Theme settings** to review colors, typography, and component styles.
